# 🎪 Arraiá Pay

## 📌 Sobre o Projeto

O **Arraiá Pay** é um projeto desenvolvido com o objetivo de organizar as etapas de criação de um sistema, desde o planejamento e levantamento dos requisitos até a modelagem e finalização do banco de dados.

## 📅 Cronograma do Projeto

| Data | Etapa | Descrição |
|---|---|---|
| 03–06/08 | Início do Projeto | Seleção dos grupos, definição das barracas e dos produtos. |
| 10–13/08 | Planejamento | Utilização do Planner e finalização dos requisitos funcionais. |
| 17–20/08 | Modelagem do MER | Criação, desenvolvimento e finalização do Modelo Entidade-Relacionamento (MER). |
| 24/08 | Desenvolvimento do DER | Criação e desenvolvimento do Diagrama Entidade-Relacionamento (DER). |
| 08/09 | Finalização do DER | Revisão, ajustes e finalização do diagrama. |
| 21/09 | Finalização do Banco de Dados | Conclusão e revisão da estrutura do banco de dados. |

## 🗂️ Etapas do Projeto

### 📅 03–06/08 — Início do Projeto

- Início do projeto Arraiá Pay.
- Seleção e organização dos grupos.
- Definição das barracas e dos produtos.

### 📅 10–13/08 — Planejamento

- Planejamento das atividades utilizando o Planner.
- Levantamento dos requisitos do sistema.
- Finalização dos requisitos funcionais.

### 📅 17–20/08 — Modelagem do Banco de Dados

- Criação do Modelo Entidade-Relacionamento (MER).
- Desenvolvimento e ajustes da modelagem.
- Finalização do MER.
- Conclusão do planejamento no Planner.

### 📅 24/08 — Desenvolvimento do DER

- Criação do Diagrama Entidade-Relacionamento (DER).
- Organização das entidades e dos relacionamentos.
- Representação gráfica da estrutura definida no MER.

### 📅 08/09 — Finalização do DER

- Revisão do diagrama.
- Correção de possíveis inconsistências.
- Finalização do DER.

### 📅 21/09 — Finalização do Banco de Dados

- Conclusão da estrutura do banco de dados.
- Revisão das tabelas e dos relacionamentos.
- Verificação das chaves primárias e estrangeiras.
- Finalização do banco de dados do Arraiá Pay.

## 🛠️ Ferramentas e Modelagens

- **Planner:** organização e planejamento das atividades.
- **Requisitos Funcionais:** definição das funcionalidades do sistema.
- **MER:** representação conceitual dos dados.
- **DER:** representação gráfica das entidades e dos relacionamentos.
- **Banco de Dados:** armazenamento e organização dos dados do sistema.

## 🎯 Objetivo Final

Concluir as etapas de planejamento, modelagem e desenvolvimento do banco de dados do **Arraiá Pay**, garantindo uma estrutura organizada e consistente para o projeto.
